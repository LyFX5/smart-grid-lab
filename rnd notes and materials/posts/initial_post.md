I’m building an early-stage project: Smart Grid Lab — an interactive microgrid laboratory in Python + Dash.

The vision is to scale in steps:

stand (educational/demo) -> digital twin (engineering experimentation) -> research platform (comparable scenarios and control studies).

Why I started this: Many teams still test microgrid ideas in disconnected tools and static studies.
I want a practical environment where you can:

configure scenarios quickly,
run simulations with reproducible setups,
compare results across use-cases,
and make the workflow transparent for both engineers and researchers.
Current status (very early):

interactive UI for setup + simulation run,
configurable battery/load/solar inputs,
trajectory visualization,
first work on application/infrastructure layers (including JSON setup persistence).
